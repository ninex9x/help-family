# Roadmap

O roadmap registra a evolução do help-family sem prometer datas. A aplicação e
os dados de saúde continuam local-first; apenas uma demonstração estática e
fictícia da interface é publicada.

## Entregue

- [x] Interface responsiva para web local e Android
- [x] Perfis de familiares com foto e observações médicas
- [x] Catálogo de medicamentos e múltiplas apresentações
- [x] Regras de uso e agenda diária por familiar
- [x] Registro de doses tomadas ou não tomadas
- [x] Histórico pesquisável, filtrável e paginado
- [x] Documentos de saúde com visualização de imagens e PDFs
- [x] Scanner multipágina no Android
- [x] Persistência local com revisão e concorrência otimista
- [x] Criptografia AES-256-GCM no backend local
- [x] Android Keystore e arquivos nativos cifrados
- [x] Temas claro e escuro persistentes
- [x] Testes, builds reproduzíveis, CI e varredura de segredos
- [x] Repositório público com backup privado independente
- [x] Demonstração estática isolada no GitHub Pages com dados por sessão

## Próximas melhorias

- [ ] Adicionar testes ponta a ponta dos fluxos críticos
- [ ] Realizar auditoria WCAG e documentar acessibilidade
- [ ] Criar exportação e restauração de backup local cifrado
- [ ] Ampliar testes instrumentados da bridge Android
- [ ] Adicionar lembretes locais sem depender de serviços externos
- [ ] Melhorar impressão e compartilhamento local de relatórios
- [ ] Documentar migrações de dados entre versões do aplicativo

Sugestões podem ser abertas como issue usando somente dados fictícios.
Vulnerabilidades devem seguir a política em [SECURITY.md](../../.github/SECURITY.md).
